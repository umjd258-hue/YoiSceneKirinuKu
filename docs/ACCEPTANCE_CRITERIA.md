# ACCEPTANCE_CRITERIA.md — 製品全体の完成条件

Stage 27完了だけでなく、以下を満たしたとき製品完成と判定する。

- 対応動画を選択できる。
- 登録人物を選択できる。
- Preflight→解析→人物別結果表示まで一巡する。
- 人物不明候補を扱える。
- AVPlayerで候補区間を確認できる。
- ユーザーが選択した区間だけMP4として保存できる。
- 元動画は変更・削除されない。
- `.partial` や破損成果物を完成扱いしない。
- 解析停止・失敗後に安全に復旧判定できる。
- SDカード抜去、容量不足、source変更をfail-closedで扱う。
- 人物登録データとEmbeddingのmodel/version不整合を検出できる。
- ネット接続なしで主要な製品機能が動作する。
- 安定error codeからユーザー向けエラーを表示できる。
- 既知問題と未完走テストが隠されていない。
- Release構成で主要導線が動作する。

- 初期版は正式対応MP4で一巡する。
- 解析だけではexportせず、ユーザー明示選択候補だけ保存する。
- 品質表示が ◎ / ○ / △ と理由で確認できる。
- 人物登録source.wavが意図しないcleanupで失われない。
- 完成済みMP4がアプリの自動cleanupで削除されない。
