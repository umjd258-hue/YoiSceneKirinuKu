# UI_SPEC.md

SwiftUI。柔らかく分かりやすいmacOSネイティブUI。

## 主要画面
- ホーム
- 動画選択
- 人物選択
- 解析中
- 結果一覧
- 動画確認
- 人物管理
- 人物登録
- 設定
- 使い方
- FAQ
- エラー/エラー分析

## 人物登録
- sample追加
- 音声/動画選択
- 動画の場合は区間選択
- 登録前確認
- 登録結果

## 結果一覧
- 人物別グループ
- 人物不明
- 品質表示
- 時刻
- プレビュー
- 保存対象を1件選択
- 折りたたみ
- 一括選択・全件折りたたみ・高度filter/sortはMVP後

## 責務分離
Viewから直接以下を実行しない。
- Process
- Python
- FFmpeg
- 重いI/O
- 永続化

Service / Repository / Job管理層へ分離する。

## エラー
Python/FFmpegの生stderrを直接UIへ出さない。
安定error code→日本語メッセージへ変換し、必要時のみ詳細を表示する。

## 品質表示
初期版は原則 ◎ / ○ / △ の3段階。
可能な範囲で簡潔な理由code/説明を表示する。
判定閾値はStage 17 Gateで検証し、UIが独自に推測しない。

## UI参考画像
`references/ui/` と `docs/UI_REFERENCE_INDEX.md` を参照。文章仕様を優先する。

## 最終UI不変条件
- 初期版の主要画面は Home / Analysis / Results / Characters の4系統。
- 独立Settings画面は初期版の主要画面として実装しない。
- 参考画像03は視覚参考として収録するが、機能採用を意味しない。
- 参考画像15の高度なエラー分析AIは初期版に追加しない。安定error code・説明・対処導線を基本とする。


## 参考画像の位置づけ
`references/ui/` の9枚は、仕様書と内容が異なる場合があるため **あくまで参考程度** とする。
文章仕様・DECISIONS・Gate・データ契約が常に優先される。
画像に描かれた未確定機能・数値・モデル名・設定項目を、そのまま実装要件にしてはならない。
