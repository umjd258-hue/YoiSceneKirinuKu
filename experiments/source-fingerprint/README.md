# Source fingerprint候補比較検証

プロジェクト内の人工ファイルだけを使用し、Source fingerprint候補の変更検出能力、見逃し、処理時間、読取り量を比較する第0段階の隔離実験です。

比較対象は、ファイルサイズ、サイズ＋更新時刻、サイズ＋更新時刻＋部分SHA-256、サイズ＋部分SHA-256、サイズ＋全体SHA-256です。部分ハッシュの範囲、人工ファイルのサイズ、反復回数その他の値は実験条件であり、本番仕様ではありません。

生成物と実測JSONは `artifacts/` に置き、Git管理しません。外部依存、外部アクセス、ユーザー動画は使用しません。
