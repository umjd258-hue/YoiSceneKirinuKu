# 外部SDカードI/O 技術検証結果

## 1. 検証目的

通常接続状態の外部SDカードについて、ユーザーが承認した専用実験ルート内だけで、次の処理が成立するかを確認した。

- partialファイルの新規作成
- 書込み後の読戻し
- bytes完全一致とSHA-256一致
- partialから正式名へのrename
- rename後の再検証
- 日本語と空白を含むパス
- 実験専用ファイルと空の実験ルートだけを対象とした安全な後片付け

本検証は通常接続状態での限定的な成立性確認であり、切断、再接続、復旧、本番保存方式は対象外とした。

## 2. 検証環境の記録

- Device Identifier: `disk6s1`
- Device Node: `/dev/disk6s1`
- Volume UUID: `F042C88B-D87C-3882-8F4D-74CAD46B4F46`
- Volume Name: `Untitled`
- Mount Point: `/Volumes/Untitled`
- Filesystem: ExFAT
- Bus: USB
- Internal: `false`
- Removable: `true`
- Writable: `true`
- Mounted: Mount Pointあり
- Python: 3.13.14
- Python path: `/Library/Frameworks/Python.framework/Versions/3.13/bin/python3`
- 外部依存追加: なし
- 外部アクセス: なし

これらは今回のローカル検証環境の記録である。Device Identifier、Volume UUID、mountpoint、ExFAT、個別のSDカードを本番仕様として固定しない。また、今回の結果をExFAT全般または他のSDカードへ一般化しない。

## 3. 操作範囲

変更対象は次の専用実験ルートだけに限定した。

```text
/Volumes/Untitled/YoiSceneKirinuKu_Experiment_20260808
```

作成したpartialファイル:

```text
/Volumes/Untitled/YoiSceneKirinuKu_Experiment_20260808/日本語 空白 読み書きテスト.partial
```

rename後の正式ファイル:

```text
/Volumes/Untitled/YoiSceneKirinuKu_Experiment_20260808/日本語 空白 読み書きテスト.txt
```

SDカード上の既存動画、写真、既存ファイル、既存フォルダは操作対象にしなかった。切断試験は行わなかった。

## 4. 安全対策

- 操作開始前、rename前、削除前にデバイス識別情報を照合した。
- mountpointと実験ルート名を固定した。
- 実験ルートが既存なら再利用、上書き、削除を行わず停止する設計とした。
- mountpoint、実験ルート、対象ファイルのsymlinkを拒否した。
- `..` とpath traversalを拒否した。
- 操作対象を実験ルート直下の固定ファイル名に限定した。
- partialを排他的な新規作成モードで作成した。
- rename先が既存なら上書きしない設計とした。
- glob、ワイルドカード、再帰削除、`rm -rf`、`shutil.rmtree` を使用しなかった。
- 削除前に実験ルート直下を確認し、想定外項目があれば自動削除を停止した。

## 5. 書込み・読戻し検証

- 専用実験ルートの新規作成: 成立
- partialファイルの排他的な新規作成: 成立
- 小さなUTF-8データの書込み: 成立
- flush: 成立
- `fsync`: 成立
- partialの読戻し: 成立
- 期待bytesとの完全一致: 成立
- 期待SHA-256との一致: 成立

ファイルが存在することだけでは成功扱いせず、読戻したbytesとSHA-256の両方を検証した。

## 6. rename・rename後検証

- partialから正式名へのrename: 成立
- rename後にpartialが残っていないこと: 確認
- 正式ファイルが通常ファイルであり、symlinkでないこと: 確認
- rename後のbytes完全一致: 成立
- rename後のSHA-256一致: 成立
- 日本語と空白を含むフォルダ名・ファイル名の取扱い: 成立

## 7. 想定外項目と安全停止

削除前の専用実験ルート直下に、次の2ファイルが存在した。

```text
日本語 空白 読み書きテスト.txt
._日本語 空白 読み書きテスト.txt
```

読み取り専用調査で確認した状態:

| ファイル | 種類 | symlink | サイズ |
|---|---|---:|---:|
| `日本語 空白 読み書きテスト.txt` | 通常ファイル | いいえ | 139 bytes |
| `._日本語 空白 読み書きテスト.txt` | 通常ファイル | いいえ | 4,096 bytes |

`._日本語 空白 読み書きテスト.txt` は当初の期待集合に含まれていない想定外項目だった。そのため、実験スクリプトの削除前安全確認が働き、自動削除を停止した。

この安全停止は、想定外項目を推測で削除しなかったという点では意図どおりに機能した。一方、当初設計した「正式ファイルを削除し、空の実験ルートを削除する」という自動後片付けは完了しなかったため、当初設計どおりの自動後片付けは未成立と判定する。

`._` ファイルの作成主体、生成理由、正式ファイル削除後に存在しなくなった理由は、本検証結果から断定しない。

## 8. 個別承認後の後片付け

想定外項目を検出した後は、自動処理を継続せず、各段階で読み取り専用確認とユーザー承認を行った。

1. 専用実験ルート直下を読み取り専用で調査し、上記2ファイルだけであることを確認した。
2. `/usr/bin/unlink` による後片付けを試みたが、この環境に同コマンドが存在せず、ファイル削除前に失敗した。
3. 再識別と再確認後、Python標準ライブラリの `Path.unlink()` で正式ファイルを削除した。
4. 続く `._` ファイルの `Path.unlink()` は `FileNotFoundError` となったため、その時点で停止した。
5. 読み取り専用で再確認した結果、専用実験ルート直下の項目数は0で、`._` ファイルはその時点では存在しなかった。
6. `._` ファイルが存在しなくなった理由は断定しなかった。
7. 再承認後、完全に空であることを確認した専用実験ルートだけを非再帰の `/bin/rmdir` で削除した。
8. 実験ルートが存在しないこと、SDカードのmountpointが存在すること、デバイス識別情報が変わっていないことを確認した。

個別承認と再確認を経た最終的な後片付けは完了した。SDカード上に専用実験ルートは残っていない。

## 9. 総合判定

限定した通常接続環境では、専用実験ルート内でのpartial書込み、読戻し、bytes／SHA-256照合、rename、rename後検証、日本語・空白パスの技術的成立性を確認した。

一方、当初想定しない `._日本語 空白 読み書きテスト.txt` が確認され、当初設計どおりの自動後片付けは未成立だった。安全ガードは想定外項目を検知し、推測による自動削除を行わず停止できた。個別承認と複数回の再確認を経た後片付けは最終的に完了した。

したがって、検証全体を「完全成功」とは判定しない。また、SDカード保存全般、ExFAT全般、他のSDカード、切断・復旧、本番保存方式の成立を示すものではない。
