# 多重起動・二重解析防止候補の比較検証

プロジェクト内の人工ジョブだけを使い、排他的ファイル作成、排他的ディレクトリ作成、`fcntl.flock`、`flock`＋所有者メタデータの候補を比較する第0段階の隔離実験です。

排他取得、同時競合時の拒否、実験用子プロセスの異常終了後の挙動、stale排他の明示回収後の再取得を確認します。方式、競合数、待機時間、stale時間、PID、heartbeat、owner tokenは本番仕様ではありません。

生成物と実測レポートは `artifacts/` に置き、Git管理しません。外部依存、外部アクセス、本体の `current_job` は使用しません。
